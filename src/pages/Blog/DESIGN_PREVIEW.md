# 博客模块设计预览

## 🎨 视觉效果展示

### 1. 博客列表页

#### Hero 区域
```
┌─────────────────────────────────────┐
│                                     │
│        记录技术与思考                 │  ← 48px, font-weight: 700
│     分享前端开发、系统设计与生活感悟   │  ← 18px, color: #666
│                                     │
└─────────────────────────────────────┘
```

#### 分类 Tab（下划线指示器风格）
```
全部    前端    后端    系统设计    生活感悟
━━━━                                   ← 2px 黑色下划线
```

**样式特点：**
- 无背景色，纯文字
- 选中态：`#000`（深黑）
- 未选中：`#999`（浅灰）
- 字间距微宽（`letter-spacing: 0.02em`）
- 流畅的滑块动画

#### 文章卡片（悬停前）
```
┌──────────────────────────────────────────┐
│                                          │
│  React Hooks 最佳实践                     │  ← 24px, font-weight: 600
│                                          │
│  本文介绍 React Hooks 的使用技巧和常见     │  ← 15px, color: #666
│  陷阱，帮助你写出更优雅的代码...           │     限制 2 行
│                                          │
│  ⏱ 5 分钟  👁 128 次  🏷 前端  2024-01-15│  ← 13px, color: #999
│                                          │
└──────────────────────────────────────────┘
```

#### 文章卡片（悬停后）
```
         ↑ 上浮 4px
    ╔══════════════════════════════════════╗
    ║                                      ║
    ║  React Hooks 最佳实践  →             ║  ← 标题变蓝 #1677ff
    ║                                      ║     箭头滑入
    ║  本文介绍 React Hooks 的使用技巧和    ║
    ║  常见陷阱，帮助你写出更优雅的代码...   ║
    ║                                      ║
    ║  ⏱ 5 分钟  👁 128 次  🏷 前端  ...  ║
    ║                                      ║
    ╚══════════════════════════════════════╝
       阴影：0 12px 24px rgba(0,0,0,0.08)
```

**动画细节：**
- `transform: translateY(-4px)` - 上浮效果
- `box-shadow` 从 0 到深层阴影
- 标题颜色过渡到蓝色
- 右侧箭头从透明 + 左移 8px 到完全显示

#### 加载更多按钮
```
         ┌──────────────┐
         │  加载更多     │  ← 悬停时上浮 2px + 阴影
         └──────────────┘
```

## 📐 尺寸规范

### 间距系统
```
卡片内边距:     32px
卡片间距:       32px
元数据间距:     24px
标题下方间距:   12px / 24px / 32px
段落间距:       24px
```

### 圆角系统
```
小圆角:   4px   (行内代码)
中圆角:   6px   (按钮)
大圆角:   8px   (卡片、图片)
超大圆角: 12px  (骨架屏、代码块)
胶囊圆角: 20px  (分类标签)
```

### 阴影系统
```
轻微:   0 2px 8px rgba(0, 0, 0, 0.04)    (表格)
中等:   0 4px 12px rgba(0, 0, 0, 0.08)   (按钮悬停)
深层:   0 8px 16px rgba(0, 0, 0, 0.08)   (大按钮悬停)
悬浮:   0 12px 24px rgba(0, 0, 0, 0.08)  (卡片悬停)
```

## 🔍 细节对比

### 传统设计 vs 现代文档美学

| 元素 | 传统设计 | 现代文档美学 |
|------|---------|-------------|
| 卡片边框 | 粗重 2px #d9d9d9 | 透明或极细 1px #f0f0f0 |
| 阴影 | 固定深色 | 柔和多层，悬停加深 |
| 圆角 | 统一 4px | 分级 4/6/8/12px |
| Tab 样式 | 背景色块 | 下划线指示器 |
| 按钮 | 实心填充 | 描边为主，悬停填充 |
| 代码块 | 简单背景 | Mac 窗口装饰 |
| 加载状态 | Spinner | 骨架屏呼吸效果 |
| 悬停反馈 | 颜色变化 | 多重动画组合 |

## 🎯 设计检查清单

在部署前确认以下细节：

- [ ] Hero 标题字重是否为 700
- [ ] Tab 下划线是否为 2px 黑色
- [ ] 卡片悬停是否同时触发：上浮 + 阴影 + 标题变色 + 箭头滑入
- [ ] 代码块是否有红黄绿三个圆点
- [ ] 引用块左侧是否有 4px 蓝色边框
- [ ] 所有过渡动画是否使用 `cubic-bezier(0.4, 0, 0.2, 1)`
- [ ] 移动端是否正确隐藏了右侧箭头
- [ ] 骨架屏是否有圆角和呼吸动画
- [ ] 分隔线是否使用渐变效果
- [ ] 分类标签是否为胶囊形状（圆角 20px）

---

**提示**: 建议在 Chrome DevTools 中使用 Lighthouse 检查性能，确保动画流畅度达到 60fps。
